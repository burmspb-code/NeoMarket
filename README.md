# NeoMarket 🔐🛒

Профессиональный интернет-магазин дверных замков, фурнитуры и аксессуаров, построенный на базе веб-фреймворка Django.

## 🛠️ Экосистема проекта (4 Рабочих Приложения)

Архитектура проекта разделена на изолированные модули согласно лучшим практикам разработки:
1. **`catalog`** — витрина товаров, управление категориями, замками и фурнитурой.
2. **`blog`** — публикации, статьи и маркетинговый контент для привлечения клиентов.
3. **`mailings`** — асинхронный сервис автоматических и ручных email-рассылок.
4. **`users`** — кастомная модель пользователей (авторизация по Email) и личные кабинеты.

## 🚀 Быстрый запуск проекта для проверки (В один клик)

В проекте полностью автоматизировано развертывание всей инфраструктуры (база данных, фикстуры, кэш, фоновые роботы). 

### Предварительные требования
Перед запуском убедитесь, что на вашем компьютере установлен и запущен локальный **Redis-сервер** на стандартном порту `6379`.

### Вариант А: Если вы на Windows
1. Кликните два раза по файлу **`start_project.bat`** в корне репозитория (или запустите его через терминал).
2. Скрипт автоматически:
   * Скопирует демонстрационный файл `.env.sample` в рабочий `.env`.
   * Установит все зависимости через Poetry.
   * Накатит миграции и Data-миграцию `0003` для настройки групп доступа [Template].
   * Загрузит демонстрационные UTF-8 фикстуры каталога, блога, рассылок и прав [Template].
   * Вызовет кастомную команду `createadmin` для инициализации суперпользователя [Template].
   * Откроет 3 независимых аккуратных окна с логами сайта и Celery-роботов.
3. Перейдите по адресу: `http://127.0.0.1:8000`

### Вариант Б: Если вы на macOS / Linux
1. Откройте терминал в корне проекта и выполните команду:
   ```bash
   chmod +x start_project.sh
   ./start_project.sh
   ```
2. Скрипт развернет всю экосистему в фоновом режиме. Для полной остановки проекта достаточно нажать `Ctrl + C` в этом же окне.

## 🔑 Учетные данные для проверки

Автоматика развертывания сама создаст в системе профили со следующими доступами:

* **Панель Администратора:** `http://127.0.0`
  * **Логин (Email):** `admin@neomarket.local`
  * **Пароль:** `admin`
  *(Создается кастомной консольной командой `manage.py createadmin` на основе переменных окружения) [Template].*

* **Группа «Контент-менеджеры»:**
  * Имеют полный доступ к наполнению `catalog`, `blog` и запуску `mailings` [Template].
  * Защита витрины: права на жесткое удаление (`delete`) категорий и товаров у них изъяты. К приложению `users` доступа нет.

* **Группа «Модераторы»:**
  * Имеют доступ к `catalog` и `blog` строго в режиме просмотра и изменения (для скрытия нарушающего контента через флажки публикации), без прав на создание и удаление [Template].
  * Имеют точечное право `change_customuser` в приложении `users` для блокировки и деактивации учетных записей пользователей [Template]. Доступа к `mailings` нет.

## ⚙️ Высоконагруженная асинхронная архитектура (Redis + Celery)

Сервис маркетинговых рассылок спроектирован по высшим стандартам отказоустойчивости (Highload):

* **Поклиентский цикл отправки (ТЗ):** Робот перебирает получателей в цикле персонально [Template]. Сбой отправки или блокировка одного Email не влияет на других клиентов, а в «Журнал логов» записываются детальные персональные отчеты по каждому адресату (ФИО, Email, статус доставки) [Template].
* **Транзакционный щит от дублей:** На уровне базы данных внедрена атомарная защита `@transaction.atomic` и блокировки строк `select_for_update()`. Это полностью исключает повторную отправку писем и дублирование логов при микрозадержках сети на Windows-платформах и старых версиях Redis [Template].
* **Низкоуровневый кэш (High Performance):** Контроллеры переопределены на работу с Low-Level Cache API в Redis [Template]. Страницы детального просмотра рассылок и списки категорий каталога выдают **100% Cache Hits**, разгружая сервер и отдавая данные за ~4-5 миллисекунд. Инвалидация (сброс) кэша работает ювелирно по ID объекта при его сохранении.
* **Авто-архивация:** Робот-планировщик Celery Beat каждую минуту проверяет базу данных, автоматически запуская актуальные по времени кампании и отправляя просроченные рассылки в архив (`completed`).

## 🧪 Ручная выгрузка UTF-8 фикстур (Справочник разработчика)

Если вы вносили изменения в демонстрационные данные через админку и хотите пересохранить фикстуры, используйте строго следующие команды. Флаг `-Xutf8` и параметр `--output` гарантируют сохранение чистого русского текста без "кракозябр" на Windows [Template]:

```bash
# Выгрузка групп и прав доступа
poetry run python -Xutf8 manage.py dumpdata auth.group auth.permission --output catalog/fixtures/groups_and_permissions.json --indent 4

# Выгрузка каталога товаров
poetry run python -Xutf8 manage.py dumpdata catalog --output catalog/fixtures/product_fixture.json --indent 4

# Выгрузка статей блога
poetry run python -Xutf8 manage.py dumpdata blog --output blog/fixtures/blog_fixture.json --indent 4

# Выгрузка маркетинговых рассылок
poetry run python -Xutf8 manage.py dumpdata mailings --output mailings/fixtures/mailings_fixture.json --indent 4
```
