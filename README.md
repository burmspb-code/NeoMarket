# NeoMarket

Проект интернет-магазина замков и фурнитуры.

## Инструкция по установке

Для работы проекта требуется менеджер зависимостей [Poetry](https://python-poetry.org).

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd NeoMarket
   ```

2. **Установите зависимости:**
   ```bash
   poetry install
   ```

## 🚀 Быстрый запуск проекта с демо-данными

Для того чтобы сразу увидеть проект с заполненными товарами и корректными изображениями, выполните следующие шаги:

1. **Подготовьте медиа-файлы:**
   Скопируйте демонстрационные изображения из папки `demo_images/` в локальную директорию `media/photo/` в корне
   проекта (если папки `media` или `photo` не существуют, создайте их).

2. **Примените миграции и загрузите данные:**

    * **Для Linux / macOS / Git Bash:**
        ```bash
        poetry run python manage.py migrate && poetry run python manage.py loaddata product_fixture && poetry run python manage.py runserver
        ```
    * **For Windows (PowerShell):**
        ```powershell
        poetry run python manage.py migrate; poetry run python manage.py loaddata product_fixture; poetry run python manage.py runserver
        ```

3. **Готово!** Перейдите по адресу `http://127.0.0.1:8000` для просмотра сайта.

## ⚙️ Маркетинговые рассылки (Кэширование, Redis и Celery)

В проекте реализован мощный асинхронный сервис автоматических и ручных email-рассылок клиентам NeoMarket на базе **Celery**, **Celery Beat** и базы данных **Redis**.

### 🔐 Управление кэшем и процессами
В файле `settings.py` добавлена переменная **`CACHE_ENABLED`**. По умолчанию она равна `True`. 
* Для локального тестирования и отладки фоновых задач оставьте значение `True`. 
* При запуске `python manage.py runserver` Django автоматически проверит порт `6379` и сам поднимет скрытый локальный Redis-сервер, если он выключен.

### 🚀 Запуск экосистемы автоматизации (Стандарт для Windows)
Для стабильной работы асинхронного робота на ОС Windows откройте **3 независимых окна терминала** с активированным виртуальным окружением:

1. **Терминал №1 (Веб-сайт + Redis):**
   ```bash
   python manage.py runserver
   ```
2. **Терминал №2 (Worker — обработчик отправки писем):**
   ```bash
   celery -A config worker --loglevel=info --pool=threads
   ```
   *Использует потоковый пул `threads` для полной совместимости с Python 3.14.*
3. **Терминал №3 (Beat — робот-планировщик по времени):**
   ```bash
   celery -A config beat --loglevel=info
   ```

### 💎 Особенности архитектуры и бизнес-логики:
* **Поклиентное логирование (ТЗ):** Робот перебирает клиентов в цикле персонально [Template]. Сбой отправки одного Email не влияет на других покупателей, а в «Журнал логов» записываются детальные персональные отчеты (ФИО, Email, статус доставки) [Template].
* **Транзакционная защита:** На уровне базы данных внедрена атомарная защита `@transaction.atomic` и блокировки `select_for_update()`, полностью исключающие дублирование писем и логов на Windows-платформах [Template].
* **Авто-архивация:** Робот-планировщик самостоятельно сканирует базу каждую минуту, запуская актуальные кампании и автоматически закрывая просроченные рассылки.
